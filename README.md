# AI Website Copy Generator for Local Businesses

## Future Interns – Task 1

### Project Overview

This project demonstrates the use of Artificial Intelligence and Prompt Engineering to generate professional website content for local businesses.

For this task, Crumbz Cafe, a local cafe in Chandapura, Bengaluru, was selected as the business for developing website content.

ChatGPT was used to create simple, attractive and customer-friendly website copy.

### Objectives

- Generate engaging homepage content.
- Create descriptions for different service categories.
- Develop attractive Call-to-Action (CTA) sections.
- Understand and apply Prompt Engineering techniques.
- Create structured and professional website content.

### Tools Used

- ChatGPT – AI content generation.
- Microsoft Word – Documentation.
- GitHub – Project storage and submission.

### Website Content Created

**1. Homepage Content**

Includes the headline, introduction, welcome message, food and beverage highlights, reasons to visit and contact information.

**2. Services Page**

Includes four service categories:
- Coffee and Beverages
- Bakery and Desserts
- Quick Bites and Snacks
- Cafe Food and Favourites

**3. Call-to-Action (CTA)**

Includes an attractive heading, welcoming description, invitation to visit, contact prompts and closing tagline.

### Prompt Engineering Techniques

- Role-Based Prompting
- Context-Based Prompting
- Instruction-Based Prompting
- Constraint-Based Prompting
- Structured Prompting

### Project Files

1. **Homepage_Content.docx**
   - Contains the homepage website copy.

2. **Services_Page.docx**
   - Contains descriptions of the four service categories.

3. **CTA_Content.docx**
   - Contains the Call-to-Action content.

4. **Prompt_Documentation.docx**
   - Contains the prompts and Prompt Engineering techniques used.

5. **Reusable_Prompt_Framework.docx**
   - Contains a reusable master prompt for different local businesses.

### Learning Outcomes

- Learned how to write effective AI prompts.
- Understood website copywriting fundamentals.
- Improved content structuring and editing skills.
- Learned to organize and publish project files using GitHub.

### Conclusion

This project demonstrates how Prompt Engineering can help generate engaging and professional website content for local businesses. It highlights the importance of clear instructions, relevant context and structured prompts in producing useful AI-generated content.
